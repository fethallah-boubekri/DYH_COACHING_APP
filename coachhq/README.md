# Coach HQ

App = `www/index.html` (single file). Wrapped with Capacitor.

1. Push this folder to a GitHub repo (branch `main`).
2. GitHub > Actions > "Build APK" runs automatically (or "Run workflow").
3. Download the artifact `CoachHQ-debug-apk`, unzip, install `app-debug.apk` on Android.

To change the app: edit `www/index.html`, commit, push.
